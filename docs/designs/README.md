# App designs

Two looks were mocked up for the TV app and the phone site (7 screens each, same example data).

| | Look | Status | Design board |
|---|---|---|---|
| **Design 1** | Charcoal cards, yellow accent, orange for losing/live clocks, green for passing bets. Ring gauges for props, a pace chart, step sliders, Poppins. | **In use** | https://claude.ai/artifact/MRp3snLS7BLhZcYLtzaGfF |
| **Design 2** | Deep purple, pink-to-purple gradients, glossy gradient numbers, neon line chart, check-circle lists, Plus Jakarta Sans. Mint for hits, coral for losing. | **Saved for later** | https://claude.ai/artifact/PSSWSfxpaX8JVD3pERnekd |

Each folder has `overview.png` (all screens), one PNG per screen, and `source/` (the design board's
artboards, plain HTML with inline styles, colors and sizes included).

Design 2's colors, for switching later: background `#1D1A2B`, cards `#262137`, raised `#2E2842`,
borders `#3A3354`, text `#F4F1FA`, muted `#A9A3BD`, primary `#7C5CFF`, gradient
`#FF9BC8 → #C77DFF → #7C5CFF`, hits `#5EE6A8`, losing `#FF9A76`.
